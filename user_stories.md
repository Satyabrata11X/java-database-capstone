# Smart Clinic Management System – User Stories

## 1. Admin User Stories

- As an Admin, I want to securely log in so that I can access the management system.
- As an Admin, I want to manage patient accounts so that patient information remains accurate.
- As an Admin, I want to manage doctor accounts so that doctors can access the system.
- As an Admin, I want to view all appointments so that I can monitor clinic activities.
- As an Admin, I want to manage user roles and access permissions so that only authorized users can access specific features.
- As an Admin, I want to manage the overall system so that clinic operations run smoothly.

## 2. Patient User Stories

- As a Patient, I want to register an account so that I can access the appointment portal.
- As a Patient, I want to securely log in so that I can manage my personal information and appointments.
- As a Patient, I want to view available doctors so that I can choose a suitable doctor.
- As a Patient, I want to book an appointment so that I can consult a doctor.
- As a Patient, I want to view my upcoming appointments so that I can keep track of my consultations.
- As a Patient, I want to reschedule or cancel an appointment so that I can manage changes in my schedule.
- As a Patient, I want to view my prescriptions so that I can follow the doctor's instructions.

## 3. Doctor User Stories

- As a Doctor, I want to securely log in so that I can access my dashboard.
- As a Doctor, I want to manage my availability so that patients can book appointments during my available hours.
- As a Doctor, I want to view my appointment schedule so that I can plan my consultations.
- As a Doctor, I want to view patient details so that I can understand their medical history before consultations.
- As a Doctor, I want to manage patient appointments so that I can reschedule or update appointment statuses.
- As a Doctor, I want to create and manage prescriptions so that patients can follow the recommended treatment.
- As a Doctor, I want to view my upcoming appointments so that I can prepare for consultations.
